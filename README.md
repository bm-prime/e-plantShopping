#e-plantShopping
Project Overview

e-plantShopping is a React-based plant shopping web application that provides users with an interactive online shopping experience. Users can browse available plants, view product information, add plants to their shopping cart, and manage the items in their cart.

The project demonstrates core React concepts such as components, state management, event handling, and dynamic rendering.

Features
🌱 Browse a collection of plants
🛒 Add plants to the shopping cart
➕ Increase product quantities
➖ Decrease product quantities
🗑️ Remove products from the cart
💰 View the total cost of selected products
📱 Responsive and user-friendly interface
Technologies Used
React
JavaScript
HTML
CSS
Vite
Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/e-plantShopping.git

Navigate to the project directory:

cd e-plantShopping

Install the required dependencies:

npm install

Start the development server:

npm run dev

The application will then be available at the local development URL provided by Vite.

Usage
Open the application in your browser.
Browse the available plants.
Select a plant and add it to your shopping cart.
Adjust the quantity of products using the quantity controls.
Remove products when they are no longer needed.
Review the total cost of your shopping cart.
